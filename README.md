# CALCULADORA DE MÉDIAS

Projeto desenvolvido em Python utilizando TDD (Test Driven Development) e utilizando pytest.

## Como Funciona ?

Para executar os testes, no terminal execute: 

```bash
pytest -v
```

Para verificar a cobertura, no terminal execute:

```bash
pytest --cov=calculadora -v
```
